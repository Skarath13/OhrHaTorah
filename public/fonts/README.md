# Site fonts

Unmodified Adobe Source Sans 3 and Source Serif 4 variable WOFF2 distributions. Both licensed under SIL OFL 1.1; see adjacent license files. These files include the complete upstream character sets, despite the latin filename distinguishing them from the system Hebrew fallback.

Source Sans: https://github.com/adobe-fonts/source-sans/tree/87b37a2daaed80fcb8e8ccb0085c4d72ddade12e
Source Serif: https://github.com/adobe-fonts/source-serif/tree/5f220b17d27ed64873f22cde0dd593685387bd19

Downloaded September 4, 2026. Upright faces are preloaded; italics load only when used. No external font request.
