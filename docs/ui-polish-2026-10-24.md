Updated October 24, 2026. Implemented locally; no commit, push, deployment, database operation, or outgoing message has been performed.

## Considered and deliberately left alone

- Services time badges read "2:30 PM" while the rest of the site uses "p.m.": the exact badge text is pinned by the contract test "Shabbat gathering uses the approved afternoon schedule".
- Uppercase tracked micro-labels (MAILBOX, SERVICE LOCATION, ZELLE® TAG, calendar weekday names, scripture citations): consistent system across the site; changing them is a style direction change, not polish.
- Gold left-border lead paragraphs and Parashah citation boxes: an established motif.
- Home vs interior palette tokens drift by a few hex values (e.g. #061a32 vs #061d35): unifying is a refactor.
- Interior body copy in `--interior-muted` (#59677b, ~5.0:1 on cream): passes AA; deepening would flatten hierarchy across every page.
- Holidays page still presents the past Fall 2026 programme (content freshness, not UI).
- Legacy-palette styles inside admin-only draft previews (Expect, FAQ, Events, Youth, Resources drafts) and unused `.info-section` CSS in services.astro.
- Login modal: carries unrelated uncommitted work from 2026-10-14; not touched.
